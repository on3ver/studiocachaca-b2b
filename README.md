# Studio Cachaça — Área do Revendedor

Protótipo funcional de landing page / catálogo comercial B2B.

## Como abrir
Abra `index.html` no navegador.

## Para publicar
Pode ser hospedado como site estático na Vercel, Netlify, Cloudflare Pages ou qualquer hospedagem comum.

## Antes da publicação
Edite `script.js` e preencha `price` para cada produto:

```js
price: 49.90
```

Os preços de atacado foram propositalmente deixados como `null` para não inventar dados comerciais.

Também revise em `index.html`:
- pedido mínimo;
- formas de pagamento;
- prazo de expedição;
- política de frete;
- múltiplos/caixas;
- exigência ou não de CNPJ/MEI;
- texto do FAQ.
